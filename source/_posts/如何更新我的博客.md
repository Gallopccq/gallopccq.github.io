工作原理：在本地编辑好文档后，将代码上传到仓库的source分支，并在本地渲染并上传（hexo clean && hexo g && hexo d），这样就将渲染好的代码上传到仓库的main分支。

命令：
```bash
git pull origin source
git add . 
git commit -m "add some blog"
git push origin source
hexo clean
hexo g # 如果需要可hexo s在本地查看效果
hexo d 
```
